SiteERP คู่มือการใช้งาน — โมดูลใบขอซื้อ (PR)

1. ภาพรวมใบขอซื้อ
ใบขอซื้อ (Purchase Requisition หรือ PR) ใช้สำหรับให้หน้างานแจ้งความต้องการวัสดุหรือบริการไปยังฝ่ายจัดซื้อ ทุก PR ต้องผูกกับโครงการและรหัสต้นทุน (Cost Code) เสมอ เพื่อให้ระบบจองและตัดงบประมาณได้ถูกต้อง
สถานะของ PR มี 4 แบบ ได้แก่ ร่าง, รออนุมัติ, อนุมัติแล้ว และยกเลิก

2. การสร้างใบขอซื้อ
1) ไปที่เมนู จัดซื้อ > ใบขอซื้อ > สร้างใหม่
2) เลือกโครงการ ระบบจะดึงรหัสต้นทุนที่เปิดใช้งานในโครงการนั้นมาให้เลือก
3) เพิ่มรายการสินค้า ระบุจำนวน หน่วย และวันที่ต้องการใช้ของ
4) แนบไฟล์ประกอบได้ เช่น รูปหน้างานหรือแบบก่อสร้าง ขนาดไม่เกิน 10 MB ต่อไฟล์
5) กด บันทึกและส่งอนุมัติ สถานะจะเปลี่ยนเป็น รออนุมัติ

3. ลำดับการอนุมัติใบขอซื้อ
ระบบกำหนดผู้อนุมัติตามวงเงินรวมของ PR ดังนี้
- ไม่เกิน 50,000 บาท วิศวกรโครงการเป็นผู้อนุมัติ
- 50,001 ถึง 500,000 บาท ผู้จัดการโครงการเป็นผู้อนุมัติ
- เกิน 500,000 บาท ต้องให้ผู้อำนวยการฝ่ายก่อสร้างอนุมัติเพิ่มอีกหนึ่งขั้น
ผู้อนุมัติจะได้รับแจ้งเตือนทางอีเมลและแอปมือถือ หาก PR ค้างอนุมัติเกิน 3 วันทำการ ระบบจะส่งแจ้งเตือนซ้ำไปยังหัวหน้าของผู้อนุมัติ

4. การแก้ไขและยกเลิกใบขอซื้อ
PR ที่อยู่ในสถานะร่างหรือรออนุมัติ ผู้สร้างแก้ไขได้เอง โดยกด ดึงกลับ ก่อนแก้ไข แล้วส่งอนุมัติใหม่
PR ที่อนุมัติแล้วแต่ยังไม่ถูกแปลงเป็นใบสั่งซื้อ ให้กด ยกเลิก พร้อมระบุเหตุผล ระบบจะคืนงบประมาณที่จองไว้ให้รหัสต้นทุนทันที
PR ที่ถูกแปลงเป็นใบสั่งซื้อแล้วยกเลิกไม่ได้ ต้องไปยกเลิกที่ใบสั่งซื้อแทน

5. ข้อผิดพลาดที่พบบ่อยในใบขอซื้อ
รหัส PR-E01 งบประมาณคงเหลือไม่พอ เกิดเมื่อมูลค่า PR เกินงบคงเหลือของรหัสต้นทุน ให้ติดต่อผู้ควบคุมต้นทุนโครงการเพื่อขอโอนงบ หรือแยกรายการไปใช้รหัสต้นทุนอื่นที่เหมาะสม
รหัส PR-E02 ไม่พบรหัสต้นทุน เกิดเมื่อรหัสต้นทุนถูกปิดหรือยังไม่เปิดใช้ในโครงการ ให้แจ้งผู้ควบคุมต้นทุนเปิดใช้งานรหัสนั้นก่อน
รหัส PR-E03 วันที่ต้องการใช้ของย้อนหลัง ระบบไม่อนุญาตให้ระบุวันที่ต้องการก่อนวันที่สร้าง PR ให้แก้เป็นวันปัจจุบันหรือวันในอนาคต
